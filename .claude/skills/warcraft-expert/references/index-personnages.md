## Guide d'utilisation

**Chercher un personnage ?**
1. Cherchez le nom dans ce document (Ctrl+F)
2. Trouvez les livres listés `[[livre-id]]`
3. Ouvrez la fiche du livre pour plus de détails sur ce perso
4. Consultez `[[perso-nom.md]]` pour une fiche dédiée si elle existe

**Ajouter un personnage ?**
- Si perso apparaît dans 3+ livres → ajouter en "Tier A/S"
- Si perso limité à 1-2 livres → ajouter dans "Personnages par Livre"
- Créer une fiche `perso-[nom].md` si c'est un personnage complexe

**Format des liens** :
- `[[01-of-blood-and-honor]]` = lien vers la fiche du livre
- `[[perso-tirion-fordring]]` = lien vers la fiche du personnage (si existe)
